# Smart Med Dosage Calculator

An interactive, web-based Clinical Decision Support Tool designed for pediatricians to calculate accurate drug dosages based on a child's weight, preventing critical prescription errors between milligrams and milliliters.

## 🌐 Live Project
Check out the working application here: https://smart-med-dosage.netlify.app/

## 🩺 Key Features
- **Weight-Based Calculations:** Instant translation of mg/kg pediatric formulas into exact milliliter (ml) syringe volumes.
- **Safety Window & Alerts:** Dynamic visual thresholds to prevent accidental medication overdoses.
- **Responsive UI:** Minimalist, distraction-free medical interface built for both desktop and mobile viewports.

## 🛠 Tech Stack
- **Frontend:** React.js, TypeScript
- **Styling:** Tailwind CSS
- **Infrastructure & Deployment:** Netlify CI/CD, Git

Disclaimer: This tool is for educational purposes only. It is a prototype Clinical Decision Support Tool and should not be used in real-world medical practice. Always verify drug dosages with official medical guidelines and standard formulas.
